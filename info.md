# BBQ Card

A beautiful round gauge card for monitoring BBQ and probe temperatures in Home Assistant.

## Features

- Round gauge with **draggable min/max markers**
- **Large** size for ambient/BBQ temperature
- **Small** size for meat/fish probes
- **Preset system** for target temperatures (beef, pork, chicken, fish, ...)
- **Celsius and Fahrenheit** support
- **On/Off** and **Snooze** buttons
- **Visual editor** — no YAML required
- Offline sensor detection
